# Cardiovascular-Disease-Prediction-Using-R
A group machine learning project using R to analyse cardiovascular health data, perform data cleaning and EDA, identify risk factors, and compare Logistic Regression, Decision Tree and Random Forest models using classification metrics, confusion matrices and ROC-AUC analysis.


# Cardiovascular Disease Prediction Using R

This project uses R to analyse cardiovascular health data and build machine learning models for cardiovascular disease prediction.

## Project Work

The project includes:

* Dataset loading and understanding
* Data cleaning and quality checks
* Descriptive analysis
* Exploratory Data Analysis
* Correlation analysis
* Data preprocessing
* Logistic Regression
* Decision Tree
* Random Forest
* Confusion matrices
* Accuracy, precision, recall and F1-score
* ROC curves and AUC comparison

## Tools Used

* R
* RStudio
* GitHub

## Models

The main models evaluated in the project are:

* Logistic Regression
* Decision Tree
* Random Forest

## Purpose

The purpose of the project is to analyse cardiovascular risk factors and compare machine learning models for predicting cardiovascular disease.

## Team Contribution

The work was divided among five group member  covering data loading, data quality, EDA, preprocessing, model development and final model evaluation.
